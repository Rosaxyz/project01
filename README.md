# Adventure – The Abandoned Castle

My Adventure project is a text-based game written in Java,
where you explore an old, abandoned castle. I chose a gothic
theme with mysterious items, hidden rooms and enemies.

You can explore nine rooms, pick up items, carry them with you
or leave them behind. Along the way, you can find food and
drinks that either improve your health or harm you.

The game also has a sword and a crossbow that you can equip
and use to fight enemies as you explore the castle.

Somewhere within the castle lies a hidden treasure room,
waiting to be discovered.
